# Disputas

API para gestão de disputas

<br />

# Introdução

Fornecemos uma API para consulta e gestão de chargebacks, permitindo listar, filtrar e acompanhar eventos, além de executar ações dentro do fluxo de contestação.

Ao integrar a API, os eventos de chargeback passam a ficar disponíveis de forma estruturada, viabilizando automação da operação e integração com sistemas internos.

# Autenticação

A autenticação é feita via chave estática. O processo de obtenção da chave é idêntico ao de outros endpoints/APIs já expostas aqui.

* **Escopo necessário:** Transacional.
* **Permissão:** Somente leitura.

> *Nota:&#x20;****Não****&#x20;é necessária uma chave exclusiva para esta API. Chaves existentes com este escopo e permissão podem ser reutilizadas.*

O envio da credencial segue o padrão definido na [Documentação do Pagar.me](https://docs.pagar.me/reference/autenticação-2).
