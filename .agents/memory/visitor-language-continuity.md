---
name: Visitor language continuity
description: Why language selection on the public site must carry into the application.
---

Treat the public landing and app login as one visitor journey for Portuguese, English and Spanish. A language selected before login should carry to the app's guest screens; once signed in, the account's saved locale remains authoritative. Australian English can use the English public copy.

**Why:** A visible language selector on the home page does not help international visitors if clicking through to login silently returns them to a different language.

**How to apply:** Public routes should honor the visitor's shared preference and preserve older landing preferences when possible. Keep language labels easy to find on small screens, update the document language, and localize interface copy without altering campaign, user or agent-generated content.
