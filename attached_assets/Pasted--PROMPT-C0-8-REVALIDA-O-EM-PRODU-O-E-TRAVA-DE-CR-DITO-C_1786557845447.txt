## C0.8.2 — REVALIDAR EM PRODUÇÃO

Assim que houver acesso, execute contra **produção** e cole cru, identificando o host consultado em cada bloco:

```sql
-- Inventário de persona
SELECT count(*) AS total,
       count(*) FILTER (WHERE settings ? 'persona') AS tem_chave_persona,
       count(*) FILTER (WHERE settings->'persona'->>'heygenAvatarId' IS NOT NULL) AS tem_avatar_id,
       count(*) FILTER (WHERE settings->'persona'->>'heygenVoiceId' IS NOT NULL) AS tem_voice_id,
       count(*) FILTER (WHERE settings->'persona'->>'avatarType' IS NOT NULL) AS tem_avatar_type
FROM workspaces;

-- Persona real do workspace do founder
SELECT id, name, settings->'persona' AS persona
FROM workspaces
WHERE settings->'persona'->>'heygenAvatarId' IS NOT NULL;

-- Histórico real de geração de vídeo
SELECT count(*) FILTER (WHERE media_job_id IS NOT NULL) AS com_job_id,
       count(*) FILTER (WHERE media_gen_status = 'failed') AS falhados,
       count(*) FILTER (WHERE media_gen_status = 'completed') AS completos
FROM social_presence_posts;
```

**Regra permanente, a partir de agora:** toda prova por `SELECT` deve declarar o host do banco consultado. `SELECT` sem host declarado é prova inválida.
