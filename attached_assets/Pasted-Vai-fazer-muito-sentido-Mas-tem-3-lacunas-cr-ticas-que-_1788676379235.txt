## **❌ LACUNAS CRÍTICAS:**

### **LACUNA 1: Fase 0 "Contrato Arquitetural" Está Vaga**

O documento diz:
> "desenho aprovado antes de código"

Mas não mostra QUAL é o desenho.

**O que você precisa:**

```
CONTRATO ARQUITETURAL (Fase 0) — Deve detalhar:

1. ENTIDADES CANÔNICAS
   ├─ User
   ├─ Workspace (propósito principal)
   ├─ Campaign (execução temporal)
   ├─ SocialProfile (conta em plataforma específica)
   ├─ Integration (credencial + permissões)
   ├─ Agent (função + ferramentas permitidas)
   ├─ Action (operação atômica executável)
   ├─ ContextMatrix (fatos + decisões + evidências)
   └─ AutonomyPolicy (quem pode fazer o quê, até onde)

2. INVARIANTES (NUNCA podem ser violados)
   ├─ User A NUNCA acessa Workspace de User B
   ├─ Action é rastreável até User
   ├─ ContextMatrix é versionada (nunca deletada)
   ├─ Cada Action tem evidência pré/pós
   └─ Orçamento nunca estoura sem aprovação

3. MÁQUINAS DE ESTADO
   ├─ Action: draft → approved → executing → completed/failed → compensated
   ├─ SocialProfile: connected → authorized → active/paused → disconnected
   ├─ Campaign: planning → active → paused → completed
   └─ ContextMatrix: building → stable → archived

4. DEPENDÊNCIAS DE AGENTES
   ├─ Copywriter depende de Strategist
   ├─ MediaBuyer depende de Copywriter + Targeting
   ├─ CEO depende de todos os anteriores
   └─ (desenho do DAG completo)

5. MOEDA/CRÉDITOS
   ├─ Quem gasta? (agente, user, workspace)
   ├─ Quanto custa cada operação?
   ├─ Quem aprova excedente?
   └─ Compensação de falhas? (retry grátis ou não)
```

**Ação:** Você precisa escrever este documento ANTES de pedir ao Replit qualquer código.

### **LACUNA 2: Mapeamento Entre Checklist Visual (Verde/Azul) e Maturidade (M0-M5)**

Hoje você tem:

```
✅ Verde = "Pronto"
🔵 Azul = "Implementado, não testado"
🟠 Laranja = "Não implementado"
🔴 Vermelho = "Falhou"
⚫ Preto = "Precisa ajuste"
```

Mas como isso conversa com M0-M5?

**O que você precisa (MATRIZ DE CONVERSÃO):**

```
MATURIDADE vs STATUS DO CHECKLIST

M0 (Ausente):
  = Feature não aparece no checklist OU
  = Checklist marca como 🟠 (não implementado)

M1 (Inteligência isolada):
  = Checklist marca ✅ ou 🔵
  = Agente gera saída (JSON/texto/plano)
  = Não há ferramenta/executor
  Exemplo: Agente de Targeting gera públicos em JSON, nada é criado no Meta

M2 (Ação parcial):
  = Checklist marca ✅ ou 🔵
  = Existe executor, MAS:
    - Depende de aprovação manual OU
    - Não verifica resultado OU
    - Não recupera falhas
  Exemplo: Autopost de conteúdo aprovado (existe, mas se falhar não retry)

M3 (Operação assistida):
  = Checklist marca ✅
  = Agente executa ações REAIS
  = Requer aprovação humana
  = Verifica resultado (evidência)
  Exemplo: Publicação no Instagram (agent cria, verifica URL, registra antes/depois)

M4 (Operação autônoma controlada):
  = Checklist marca ✅ E passou em testes adversariais
  = Agent executa sem aprovação (dentro de limites)
  = Recupera falhas automaticamente
  = Logging completo + evidência
  = Pode ser pausado/escalonado
  Exemplo: Meta Ads (dentro de orçamento aprovado, cria/otimiza/pausa sem humano)

M5 (Agência autônoma adaptativa):
  = M4 + múltiplos agents coordenando
  = Replaneja baseado em resultados
  = Isola workspace A de B perfeitamente
  = Testes adversariais passam
  Exemplo: CEO decompõe campanha → Strategist → Copywriter → MediaBuyer → Execution
```

**Ação:** Crie uma tabela (spreadsheet) que mapeie cada feature do checklist para sua maturidade atual.

### **LACUNA 3: Schema da Matriz Canônica Não Definido**

O documento descreve o que guardar (Seção 2B):
- Fatos
- Hipóteses
- Decisões
- Evidências
- Restrições
- Contradições
- Aprovações
- Aprendizados
- Estado operacional
- Proveniência
- Confiança
- Sensibilidade
- Versão

Mas não mostra as tabelas SQL.

**O que você precisa (SCHEMA):**

```sql
-- Tabela 1: Matriz de Fatos
CREATE TABLE context_matrix_facts (
  fact_id UUID PRIMARY KEY,
  context_id UUID NOT NULL, -- (workspace, campaign)
  
  -- Quem disse
  source_agent VARCHAR(100), -- "strategist", "copywriter", "ceo"
  source_human UUID, -- NULL se agente
  
  -- O que é
  category VARCHAR(50), -- "fact", "hypothesis", "inference", "decision", "evidence"
  assertion TEXT, -- "Avatar é 25-34 anos, feminino, renda alta"
  confidence FLOAT, -- 0.0 a 1.0
  
  -- Por quê
  provenance JSONB, -- {source, date, evidence_link}
  supporting_evidence TEXT[], -- links para fatos que suportam
  contradictions TEXT[], -- links para fatos que contradizem
  
  -- Validade
  state VARCHAR(20), -- "proposed", "accepted", "superseded", "archived"
  approved_at TIMESTAMP,
  approved_by UUID,
  expires_at TIMESTAMP, -- NULL = nunca expira
  
  -- Contexto
  sensitivity VARCHAR(20), -- "public", "internal", "restricted", "confidential"
  tags TEXT[],
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  version INT DEFAULT 1
);

-- Tabela 2: Matriz de Decisões
CREATE TABLE context_matrix_decisions (
  decision_id UUID PRIMARY KEY,
  context_id UUID NOT NULL,
  
  -- O que foi decidido
  decision_type VARCHAR(50), -- "strategy", "copy", "media", "channel", "budget"
  description TEXT,
  
  -- Quem decidiu
  decided_by_agent VARCHAR(100),
  decided_by_human UUID,
  
  -- Por quê
  rationale TEXT,
  facts_referenced UUID[], -- links para context_matrix_facts
  alternatives_considered JSONB, -- {alt1: reason rejected, alt2: ...}
  
  -- Impacto
  impact_expected JSONB, -- {reach, engagement, cost, ...}
  impact_actual JSONB, -- preenchido depois
  
  -- Aprovação
  approval_status VARCHAR(20), -- "proposed", "approved", "rejected", "superseded"
  approved_by UUID,
  approved_at TIMESTAMP,
  
  -- Próxima ação
  next_agent VARCHAR(100), -- quem executa
  dependencies VARCHAR(100)[], -- outras decisões
  
  created_at TIMESTAMP,
  superseded_by UUID -- link para próxima versão
);

-- Tabela 3: Matriz de Evidências
CREATE TABLE context_matrix_evidence (
  evidence_id UUID PRIMARY KEY,
  context_id UUID NOT NULL,
  
  -- O que é
  evidence_type VARCHAR(50), -- "log", "metric", "screenshot", "email", "api_response"
  description TEXT,
  
  -- Onde está
  evidence_url TEXT, -- GCS, arquivo, ou inline
  evidence_content TEXT, -- inline se pequeno
  
  -- Quando
  collected_at TIMESTAMP,
  collected_by_agent VARCHAR(100),
  
  -- De quê
  supports_facts UUID[], -- links
  supports_decisions UUID[], -- links
  
  -- Confiança
  confidence FLOAT,
  
  created_at TIMESTAMP
);

-- Tabela 4: Matriz - Índice Operacional
CREATE TABLE context_matrix (
  context_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID NOT NULL,
  campaign_id UUID NOT NULL,
  
  -- Snapshot (denormalizado para query rápida)
  latest_facts JSONB, -- keys: {fact_category: [fact_objects]}
  latest_decisions JSONB,
  active_constraints JSONB,
  
  -- Estado
  state VARCHAR(20), -- "building", "stable", "executing", "completed"
  
  -- Versão
  version INT,
  parent_version INT, -- se veio de iteração anterior
  
  updated_at TIMESTAMP,
  
  UNIQUE(workspace_id, campaign_id)
);
```

**Ação:** Use este schema como base. Refine com Replit.
