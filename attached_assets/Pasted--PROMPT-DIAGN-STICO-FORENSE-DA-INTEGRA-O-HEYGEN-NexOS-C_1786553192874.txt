## FASE 2 — GERAÇÃO ISOLADA, FORA DO NEXOS

Objetivo: separar definitivamente "bug do NexOS" de "limitação de conta/plano".

Usando um `avatar_id` **público/padrão retornado na FASE 1** e um `voice_id` da lista de vozes, gere um vídeo por curl direto:

```bash
curl -s -w "\n--- HTTP %{http_code} ---\n" -X POST \
  https://api.heygen.com/v2/video/generate \
  -H "X-Api-Key: $HEYGEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "video_inputs": [{
      "character": {"type": "avatar", "avatar_id": "COLE_AQUI", "avatar_style": "normal"},
      "voice": {"type": "text", "input_text": "Teste de integracao NexOS.", "voice_id": "COLE_AQUI"}
    }],
    "dimension": {"width": 1280, "height": 720}
  }'
```

Capture o `video_id` retornado e faça o polling até resolver:

```bash
curl -s -w "\n--- HTTP %{http_code} ---\n" \
  -H "X-Api-Key: $HEYGEN_API_KEY" \
  "https://api.heygen.com/v1/video_status.get?video_id=COLE_AQUI"
```

Repita até `status` = `completed` ou `failed`. Cole **todas** as respostas.

**Veredito obrigatório, escolha uma:**
- `RESULTADO A` — curl direto gerou vídeo com URL reproduzível → **a conta funciona, o defeito é 100% do código NexOS.**
- `RESULTADO B` — curl direto falhou → **cole o erro. O defeito é conta/plano/quota, não código.** Pare aqui e reporte.
