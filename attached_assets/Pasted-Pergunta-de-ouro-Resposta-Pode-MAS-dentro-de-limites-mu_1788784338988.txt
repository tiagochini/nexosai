## **OPÇÃO 1: Lookalike Audiences (LEGAL + EFETIVO)**

```
FLUXO:
┌─────────────────────────────────────┐
│ Concorrente publica campanha        │
├─────────────────────────────────────┤
│ Audiência dele: 50k pessoas         │
│ que interagem publicamente          │
│ (comentam, seguem, compartilham)    │
├─────────────────────────────────────┤
│ Você monitora via Instagram API:    │
│ "People who follow @concorrente"    │
│ "People who liked @concorrente posts"
│ "People who commented"              │
├─────────────────────────────────────┤
│ Facebook / Google permite:          │
│ "Criar audiência similar baseada em │
│ IDs de usuários que interagiram"    │
│                                     │
│ (Facebook faz matching automático   │
│  sem você ver os nomes/emails)      │
├─────────────────────────────────────┤
│ Você cria anúncio competidor        │
│ e direciona para LOOKALIKE audience │
├─────────────────────────────────────┤
│ RESULTADO:                          │
│ ✅ Legal                            │
│ ✅ Seu próprio pixel coleta dados   │
│ ✅ Remarketing depois com consentimento
└─────────────────────────────────────┘
```

**Como funciona tecnicamente:**

```
Facebook Lookalike Audience:

1. Você dá pra Facebook:
   - IDs de conta Instagram de concorrente
   - "Quero audiência similar a quem segue isso"

2. Facebook processa:
   ✓ Identifica 50k pessoas que seguem concorrente
   ✓ Encontra características em comum (localização, idade, interesses)
   ✓ Cria audiência de 1M+ pessoas COM ESSAS CARACTERÍSTICAS
   ✓ MAS que NÃO estão nos 50k originais

3. Você não vê NENHUMA informação pessoal
   (não tem acesso a emails, nomes, nada)

4. Você publica anúncio
   → Facebook mostra pra lookalike audience
   → Quem clica ativa SEU pixel
   → Agora você tem consentimento de contact
   → Remarketing é legal
```

**Status:** ✅ **TOTALMENTE LEGAL**
- Não viola GDPR/LGPD (Facebook é intermediário consentido)
- Não viola TOS (é recurso oficial da plataforma)
- Efetivo (audiência pré-segmentada é qualificada)
- Escalável (1M+ pessoas vs 50k)

## **OPÇÃO 2: Remarketing com Seu Próprio Pixel**

```
FLUXO:
┌──────────────────────────────────────┐
│ Concorrente publica conteúdo viral   │
├──────────────────────────────────────┤
│ 100k pessoas acessam o site dele     │
│ (landing page, blog post, etc)       │
├──────────────────────────────────────┤
│ Seu pixel está em rede de:           │
│ - Programmatic ads (display network) │
│ - Google Ads (rede de display)       │
│ - Qualquer site que você patrocina   │
│                                      │
│ = Pixel tracks essas 100k pessoas    │
│   em NAVEGAÇÃO POSTERIOR             │
├──────────────────────────────────────┤
│ Você cria remarketing audience:      │
│ "People who visited competitor site" │
├──────────────────────────────────────┤
│ Publica anúncio seu pra eles:        │
│ "Procurando alternativa? Testou X?"  │
└──────────────────────────────────────┘
```

**Como é legal:**

1. Pixel é consentido (rastreamento web é legal se divulgado em privacy policy)
2. Você não sabe quem são (apenas "audience segment")
3. Remarketing oferece alternativa (não é stalking, é marketing)
4. Dados colhidos por você, com seu consentimento implícito (uso do site)

**Status:** ✅ **LEGAL** (com privacy policy adequada)

## **COMPLIANCE CHECKLIST (Antes de Usar)**

```
❌ Não pode:
   □ Usar dados privados (emails, phones) do concorrente
   □ Contactar sem consentimento
   □ Declarar que faz o mesmo que concorrente (false advertising)
   □ Fazer spam

✅ Pode:
   □ Monitora campanhas públicas
   □ Cria lookalike audiences
   □ Usa remarketing com seu próprio pixel
   □ Oferece alternativa legítima melhor/diferente
   □ Anunciar para mesma audiência-alvo

📋 Privacy Policy precisa mencionar:
   □ "Usamos pixels para rastreamento de conversão"
   □ "Criamos remarketing audiences baseadas em comportamento"
   □ "Dados são processados por Facebook/Google"
   □ "Opt-out disponível [link]"

✅ Consentimento:
   □ Pixel é consentido (implícito: visitou seu site)
   □ Form é consentido (explícito: preencheu)
   □ Email é consentido (opt-in no form)
   □ Tudo auditável
```
